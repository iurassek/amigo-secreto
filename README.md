Amigo Secreto

Este projeto é uma aplicação simples para gerenciar e sortear participantes de um amigo secreto.
Ele utiliza HTML, CSS e JavaScript para proporcionar uma interface interativa e fácil de usar.

Funcionalidades
•	Adicionar participantes: Os usuários podem adicionar nomes à lista de participantes.
•	Remover participantes: Nomes adicionados podem ser removidos antes do sorteio.
•	Sortear amigo secreto: Sorteia os pares de participantes, garantindo que ninguém tire a si mesmo.

Estrutura de Arquivos
•	index.html: Estrutura principal do projeto.
•	style.css: Estilos utilizados na interface.
•	app.js: Lógica da aplicação (adicionar, remover e sortear participantes).

Como Usar
1.	Clone o repositório:
2.	git clone https://github.com/seu-usuario/amigo-secreto.git
3.	Navegue até o diretório do projeto:
4.	cd amigo-secreto
5.	Abra o arquivo index.html em seu navegador.
6.	Adicione os nomes dos participantes e clique no botão "Adicionar".
7.	Quando todos os participantes forem adicionados, clique no botão "Sortear amigo secreto" para ver os pares.
